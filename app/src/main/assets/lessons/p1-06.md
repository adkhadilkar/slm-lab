# Sampling: temperature and top-k

## The idea

A model's last layer outputs logits, one number per token in the vocabulary. Softmax turns the logits into probabilities, and sampling picks one token according to them. Two settings change how that choice is made, without any retraining. Temperature rescales the logits before softmax. Top-k discards all but the k most likely tokens before sampling.

Worked example with logits [2.0, 1.0, 0.0] for three tokens. At temperature 1 the exponentials are 7.389, 2.718 and 1, with sum 11.107. The probabilities are 0.665, 0.245 and 0.090.

At temperature 0.5 the logits are divided by 0.5 first, giving [4, 2, 0]. The exponentials are 54.598, 7.389 and 1, with sum 62.987. The probabilities are 0.867, 0.117 and 0.016. The lower temperature sharpens the distribution, so the most likely token gets most of the mass.

Top-k with k = 2 at temperature 1 drops the third token and renormalizes the other two. The sum of their exponentials is 10.107, so the probabilities are 0.731 and 0.269.

## How it works

Given logits z, a temperature T and an optional k:

1. Divide: z' = z / T. The temperature must be greater than 0.
2. Softmax: `p_i = exp(z'_i) / sum over j of exp(z'_j)`.
3. If k is set, keep the k largest probabilities, set the rest to 0, and divide by the new sum.
4. Draw one token from p.
5. Append the token to the text and repeat.

As T approaches 0, sampling approaches picking the most likely token every time. Top-k with k = 1 is always greedy. A high temperature flattens the distribution towards uniform, so rare tokens appear more often. The core is short:

```python
z = logits / temperature
p = softmax(z)
if top_k is not None:
    cut = np.sort(p)[-top_k]
    p = np.where(p >= cut, p, 0.0)
    p = p / p.sum()
token = rng.choice(len(p), p=p)
```

Ties at the cut-off can keep a few extra tokens. That is harmless for teaching.

## In the lab

`lab05_sampling.py` loads the model saved by the training lab. If no model exists it prints how to create one and stops. For one prompt it prints samples at temperatures 0.3, 0.8 and 1.5, and with top-k set to 1, 5 and none. It also prints the top 8 next-character probabilities for the prompt at two temperatures, so you can see the distribution the samples come from.

Try these:

1. Use the same prompt at temperature 0.3, then at 1.5. Which output looks more repetitive, and which looks more random? Explain why in terms of the probabilities.
2. Compare top-k 1 with no top-k at temperature 0.8. Why does top-k 1 give the same text every time, even with a different seed?
3. Change the prompt to a line from another part of the corpus and read the probability table again. Does the top candidate change, and how much probability does it get?
