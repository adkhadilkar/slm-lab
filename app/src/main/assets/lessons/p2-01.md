# Choosing a pretrained small model

## The idea

Training a language model from scratch needs far more data and compute than this course assumes. The practical route is to start from a pretrained model, one trained on a large amount of text and published with its weights. Choosing one comes down to four things: its size (the parameter count), whether it is a base model or an instruct model, its licence, and whether it fits the hardware you have.

Worked example of memory. A model with 1 billion parameters stored as 16-bit floats uses 2 bytes per parameter, so its weights take 1e9 x 2 bytes = 2 GB. The same model quantized to 4 bits uses 1e9 x 0.5 bytes = 0.5 GB. The weights are only part of the cost. The context cache, activations and the framework add overhead, so budget more than the weights alone.

## How it works

1. Decide the task. Chat and general questions suit an instruct model. Continuing a piece of text suits a base model.
2. Open the model hub and filter for small models. Read the parameter count, the context length and the licence text. Some licences limit commercial use or redistribution.
3. Estimate memory: parameters times bytes per parameter, plus overhead. Compare the result with the memory of your GPU or laptop.
4. Read the model card for its chat template. The tokenizer uses the template to wrap your messages in the format the model was tuned on.
5. Load the tokenizer and the model, apply the chat template, then generate.

The options on the hub change over time. Check it for the current models and their licences, and do not rely on a list from a course.

Library APIs change over time, so check the current Hugging Face `transformers` documentation before running this sketch.

## Steps

1. Open a Colab notebook and choose a GPU runtime, or use a laptop with enough memory.
2. Install the libraries with `pip install transformers`, and add `torch` if it is not already there.
3. Pick a small instruct model from the hub. Write its ID in `MODEL_ID` and record its licence.
4. Run the code below and read the reply. Note how long the first load takes.
5. Change the question and run again. Notice how the answer changes with the wording and the template.

```python
# Starting sketch. Check current docs for exact APIs.
from transformers import AutoTokenizer, AutoModelForCausalLM

MODEL_ID = "your-chosen-small-model"  # check licence

tokenizer = AutoTokenizer.from_pretrained(MODEL_ID)
model = AutoModelForCausalLM.from_pretrained(MODEL_ID)

messages = [{"role": "user", "content": "What is a token?"}]
text = tokenizer.apply_chat_template(
    messages, tokenize=False, add_generation_prompt=True)
inputs = tokenizer(text, return_tensors="pt")
inputs = inputs.to(model.device)
out = model.generate(**inputs, max_new_tokens=100)
n = inputs["input_ids"].shape[1]
print(tokenizer.decode(out[0][n:]))
```
