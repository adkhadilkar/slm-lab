# The transformer block

## The idea

A GPT is an embedding layer, a stack of identical blocks, and an output head. Each block has two parts. Attention moves information between tokens. The MLP processes each token's vector on its own. Both parts are wrapped the same way: normalize the input, transform it, and add the result back to the input. That add-back is the residual connection.

Worked example of LayerNorm. Take the vector [1, 2, 3]. Its mean is 2. Its variance is ((1 - 2)^2 + 0 + (3 - 2)^2) / 3 = 2/3. Its standard deviation is sqrt(2/3) = 0.816. The normalized vector is [-1.225, 0, 1.225]. LayerNorm gives each token's vector zero mean and unit variance across its features. A learned gain and bias are applied afterwards, and a small epsilon guards against division by zero.

Worked example of a residual connection. Suppose the input to a sub-layer is [1.0, 0.5] and the sub-layer adds [0.1, -0.2]. The output is [1.1, 0.3]. If the sub-layer learned nothing useful and output zeros, the input would pass through unchanged. This is why deep stacks train.

## How it works

The block uses pre-norm ordering. For input x of shape (T, `d_model`):

1. x = x + attention(LayerNorm(x))
2. x = x + mlp(LayerNorm(x))

Pre-norm means each sub-layer sees a normalized input, while the residual path carries the un-normalized x straight through. Gradients can flow down that path without passing through every transformation.

The MLP widens the vector to four times `d_model`, applies GELU, and projects back. GELU uses the tanh approximation, so the MLP is `d_model -> 4 * d_model -> d_model`. The factor of four is a convention in GPT-style models, and it sets most of the block's parameters.

## Reading the code

Here is the structure of the model in `tinygpt.py`, written as pseudocode with the shapes:

```
x = tok_emb[tokens] + pos_emb[0:T]     # (B, T, d)
for each of n_layer blocks:
    x = x + causal_attention(layer_norm(x))
    x = x + mlp(layer_norm(x))
x = layer_norm(x)                      # final LayerNorm
logits = x @ W_head + b_head           # (B, T, vocab)
```

The MLP inside each block is:

```
h = x @ W1 + b1          # (T, d) -> (T, 4d)
h = gelu(h)
out = h @ W2 + b2        # (T, 4d) -> (T, d)
```

The final LayerNorm keeps the head's input scaled consistently, whatever the depth. The linear head is separate from the token embedding, so the two weight matrices are not tied together. The head maps each position's vector to one score per vocabulary entry.
