# What a language model does

## The idea

A language model is a function that, given the text so far, gives a probability to every possible next token. Here a token is a single character, so the vocabulary is the set of distinct characters in the text. If the vocabulary has 65 characters, the model must output 65 numbers that add up to 1.

Take a toy vocabulary of two characters, `a` and `b`, and the text `aaab`. Look at the three transitions: `a` to `a`, `a` to `a`, and `a` to `b`. A bigram model counts how often each character follows each other character. After `a` it saw `a` twice and `b` once, so it predicts P(a after a) = 2/3 and P(b after a) = 1/3.

We score the model with the negative log-likelihood (NLL) of the character that actually came next: NLL = -ln(p), where p is the probability given to that character. A confident correct guess has p close to 1 and NLL close to 0. A guess of p = 0.1 costs -ln(0.1) = 2.30.

The three transitions of `aaab` cost -ln(2/3) = 0.405 for each `a` to `a` step and -ln(1/3) = 1.099 for the `a` to `b` step. The average is (0.405 + 0.405 + 1.099) / 3 = 0.64.

A model that knows nothing gives every character probability 1 / vocab, so its NLL is ln(vocab). With two characters that is ln 2 = 0.69, so the bigram model at 0.64 beats the uniform model. With 65 characters the uniform baseline is ln(65) = 4.17. A useful model must score below that.

## How it works

A bigram model keeps one table of counts with a row for each previous character. Training is counting:

1. Read the text and build the vocabulary.
2. For each adjacent pair (previous, next), add 1 to `counts[previous][next]`.
3. Divide each row by its total so that each row sums to 1. This gives P(next given previous).
4. Measure the average NLL over the pairs of held-out text.
5. To generate, start from one character, sample the next character from its row, and repeat.

The core of the counting and scoring is short:

```python
counts[prev][nxt] += 1
probs = counts / counts.sum(axis=1, keepdims=True)
loss = -np.mean(np.log(probs[prev, nxt]))
```

The limit of a bigram model is that it looks only one character back. A bigram model cannot know that a quote mark opened fifty characters earlier. Later lessons add more context.
