# Tokens and BPE

## The idea

A model never sees raw text. It sees a sequence of integer token ids. Characters give a small vocabulary but long sequences, so the model does more work per word. Whole words give short sequences but a huge vocabulary, and rare words are never seen in training. Byte-pair encoding (BPE) sits between the two. It starts from single characters and repeatedly merges the most frequent adjacent pair into a new token.

Worked example. Start with the string `abababc` as seven single characters. The adjacent pairs are `ab` three times, `ba` two times and `bc` once. The most frequent pair is `ab`, so we merge it into a new token `X`. The string becomes `XXXc`: seven characters are now four tokens.

Next round, the pair `XX` occurs twice, so we merge it into a new token `Y`. The string becomes `YXc`, three tokens. The compression ratio is 7 characters for 3 tokens, about 2.3 characters per token.

## How it works

Learning the merges:

1. Start with the vocabulary of single characters (or bytes).
2. Count every adjacent pair of current tokens in the training text.
3. Take the most frequent pair, add it to the vocabulary as a new token, and record the merge rule.
4. Replace occurrences of that pair with the new token, scanning left to right without overlaps.
5. Repeat for `NUM_MERGES` steps.

Encoding new text starts from characters and applies the recorded merges in the order they were learned. Decoding looks up each token id in the vocabulary and joins the strings. No merge rules are needed for decoding, and `decode(encode(text))` must give back `text`.

Order matters. The `Y` merge depends on the `X` merge. If you applied the `XX` rule first, it would find nothing in `abababc`, and the result would differ. A merge sketch looks like this:

```python
def merge(seq, pair, new_id):
    out, i = [], 0
    while i < len(seq):
        ok = i + 1 < len(seq) and (seq[i], seq[i+1]) == pair
        if ok:
            out.append(new_id)
            i += 2
        else:
            out.append(seq[i])
            i += 1
    return out
```
